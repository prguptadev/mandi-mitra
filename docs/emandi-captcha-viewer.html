e-Mandi captcha viewer

Paste what the portal answered and this page shows it. It only displays what you paste — it does not call e-Mandi, and it does not read the captcha for you.

Nothing leaves this page except loading the image itself.

What it says is for a person to read and type.
What this is for. Looking at a reply while working on the portal side of Mandi Mitra — the image, and the token fields that have to go back with it. Mandi Mitra itself shows the same image on screen and a person types what it says; nothing in the app or on this page tries to read it.

If the picture does not appear. The address in that block is a path on e-Mandi, so this browser fetches it straight from the portal. It only comes back as a picture if this same browser is signed in there — otherwise the portal answers with its login page. And each captcha is good for one sign-in and a few minutes: once it has been used or has gone stale, that address stops giving a picture. Press refresh on the portal and paste the new block.
